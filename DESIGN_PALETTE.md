# Kitsune black and yellow palette

| Role | Color |
| --- | --- |
| Main background | `#1D201C` |
| Charcoal surfaces | `#292D25` |
| Raised surfaces | `#2B3028` |
| Saffron yellow accents | `#E9C64B` |
| Softer yellow details | `#D9BF69` |
| Main text | `#EBE9DF` |
| Secondary text | `#B4B7A8` |
| Dividers | `#414638` |
| Text on yellow buttons | `#26271C` |

Yellow is concentrated in the fox emblem, primary actions, active controls, headings and prices. Hero and contact panels use gentle charcoal gradients. Body copy uses soft ivory and warm gray. Photographs provide brighter areas without large solid-yellow sections. Existing rounded frames and locally hosted Inter / Playfair Display typography are retained.
